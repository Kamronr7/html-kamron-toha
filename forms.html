HTML Forms

HTML forms are used to collect information from users. Forms can contain text fields, buttons, checkboxes, dropdowns and other input elements.

<form> Tag

Definition

The <form> tag is used to create an HTML form for collecting user input.

Attributes

Attribute Role
action Specifies where the form data will be sent.
method Specifies how the form data will be sent.

Example Code

<form>
    <input type="text">
</form>

Result

<label> Tag

Definition

The <label> tag is used to describe an input field.

Attributes

Attribute Role
for Connects the label to an input element.

Example Code

<label for="name">Name:</label>
<input type="text" id="name">

Result

<input> Tag

Definition

The <input> tag allows the user to enter information.

Attributes

Attribute Role
type Specifies the type of input.
name Specifies the name of the input.
placeholder Shows temporary text inside the input.
required Makes the field required.

Example Code

<input type="text" placeholder="Enter your name">

Result

<textarea> Tag

Definition

The <textarea> tag creates a multi-line text input.

Attributes

Attribute Role
rows Specifies the number of visible text rows.
cols Specifies the width of the text area.
placeholder Shows temporary text inside the field.

Example Code

<textarea rows="4" cols="30"></textarea>

Result

<select> and <option> Tags

Definition

The <select> tag creates a dropdown list. The <option> tag defines the choices inside it.

Attributes

Attribute Role
name Specifies the name of the dropdown.
value Specifies the value of an option.
selected Sets an option as selected by default.

Example Code

<select>
    <option>HTML</option>
    <option>CSS</option>
    <option>JavaScript</option>
</select>

Result

Checkbox Input

Definition

A checkbox allows the user to select one or more options.

Attributes

Attribute Role
type Set to checkbox to create a checkbox.
checked Makes the checkbox selected by default.

Example Code

<input type="checkbox"> I agree

Result

I agree

Radio Button Input

Definition

Radio buttons allow the user to select one option from a group.

Attributes

Attribute Role
type Set to radio to create a radio button.
name Groups radio buttons together.
value Specifies the value of the option.

Example Code

<input type="radio" name="language"> HTML
<input type="radio" name="language"> CSS

Result

<button> Tag

Definition

The <button> tag creates a clickable button.

Attributes

Attribute Role
type Specifies the type of button.
disabled Disables the button.

Example Code

<button type="button">Click Me</button>

Result

Complete Form Example

Example Code

<form>

    <label for="username">Name:</label>
    <input type="text" id="username" placeholder="Your name">

    <label for="email">Email:</label>
    <input type="email" id="email" placeholder="Your email">

    <button type="submit">Submit</button>

</form>
