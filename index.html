Page 1: how an HTML page is built

Every page has the same skeleton. Learn it once and you can read any page on the web.

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>Page title</title>
  <link rel="stylesheet" href="css/style.css">
</head>
<body>
  <header>…</header>
  <main>…</main>
  <footer>…</footer>
</body>
</html>
<!DOCTYPE html>
Tells the browser this is a modern HTML page.
<html>
Wraps the whole page. The lang attribute sets the page language.
<head>
Information about the page. Nothing here appears on screen except the title in the browser tab.
<body>
Everything people see: headings, text, images, links.
<header>, <main>, <footer>
Name the parts of the page: top, main content, bottom.
