Page 3: Links, images, video and audio

Links connect pages together. Images, video and audio bring your page to life. Each one is a single tag with a few attributes.

On this page: Links, Images, Video, Audio

Links: the <a> tag

The <a> (anchor) tag makes a link. The href attribute says where it goes, and the text between the tags is what people click.

<!-- Another page in your site -->
<a href="metadata.html">Go to Metadata</a>

<!-- A page on another website, opened in a new tab -->
<a href="https://developer.mozilla.org"
   target="_blank" rel="noopener noreferrer">MDN Web Docs</a>

<!-- A spot on the same page (needs a matching id) -->
<a href="#audio">Jump to Audio</a>

<!-- Email and phone -->
<a href="mailto:hello@example.com">Send an email</a>
<a href="tel:+998901234567">Call us</a>

Try these

  • Go to Metadata (same site)
  • MDN Web Docs (new tab)
  • Jump to Audio (same page)
href
The destination. A file name or path for your own pages, a full https:// address for other sites.
target="_blank"
Opens the link in a new tab. Add rel="noopener noreferrer" with it for safety.
Good link text
Write "Read the forms guide", not "click here". It helps everyone, especially people using screen readers.

Images: the <img> tag

<img> has no closing tag. Put your picture files in the images folder and point to them with src.

<img src="images/photo.jpg"
     alt="Students writing code at a laptop"
     width="400" height="250">

<!-- Add a caption with figure -->
<figure>
  <img src="images/photo.jpg" alt="Students writing code">
  <figcaption>Our first coding class</figcaption>
</figure>

Working image

Broken image: the alt text appears instead

src
The path to the image file. Check the spelling and the folder name, because a wrong path gives a broken image.
alt
A short description. Screen readers read it aloud, and it shows if the image fails to load. Always include it.
width and height
The size in pixels. Setting both stops the page from jumping as images load.

Video: the <video> tag

<video controls width="480" poster="images/cover.jpg">
  <source src="images/lesson.mp4" type="video/mp4">
  <source src="images/lesson.webm" type="video/webm">
  Your browser does not support video.
</video>
controls
Shows play, pause and volume buttons. Without it, visitors cannot start the video.
poster
A picture shown before the video plays.
<source>
Lists file formats. The browser plays the first one it understands. MP4 works almost everywhere.
Fallback text
The line inside the tag shows only in browsers that cannot play video.

Audio: the <audio> tag

<audio controls>
  <source src="images/welcome.mp3" type="audio/mpeg">
  <source src="images/welcome.ogg" type="audio/ogg">
  Your browser does not support audio.
</audio>

It works like video: controls adds the player, and <source> offers different formats. Avoid autoplay, because browsers often block it and it annoys visitors.

Practice

  1. Put a picture in your images folder and show it on a page with <img> and a good alt.
  2. Add a link from index.html to links.html.
  3. Add a short MP4 file or MP3 file and play it with controls.
