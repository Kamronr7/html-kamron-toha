Page 4: Lists

Lists group related items so they are easy to scan. HTML has three kinds: bullet lists, numbered lists and description lists.

On this page: Unordered, Ordered, Nested, Description

Unordered lists: <ul>

Use <ul> when the order of the items does not matter. Each item goes in an <li> (list item). Browsers show bullets.

<ul>
  <li>HTML</li>
  <li>CSS</li>
  <li>JavaScript</li>
</ul>

Result

  • HTML
  • CSS
  • JavaScript

Ordered lists: <ol>

Use <ol> when the order matters, such as steps or rankings. Browsers number the items for you.

<ol>
  <li>Create a folder</li>
  <li>Add index.html</li>
  <li>Open it in a browser</li>
</ol>

<ol start="5" type="A">…</ol>
<ol reversed>…</ol>

Result

  1. Create a folder
  2. Add index.html
  3. Open it in a browser

With start="5" and type="A"

  1. Starts at the fifth letter
  2. Then continues
start
The number to begin counting from.
type
The numbering style: 1, A, a, I or i.
reversed
Counts down instead of up, like a top 10 list.

Nested lists

To put a list inside another, place the inner list inside an <li>, not directly inside the outer <ul>.

<ul>
  <li>Fruit
    <ul>
      <li>Apple</li>
      <li>Banana</li>
    </ul>
  </li>
  <li>Vegetables</li>
</ul>

Result

  • Fruit
    • Apple
    • Banana
  • Vegetables

Description lists: <dl>

A description list pairs terms with their meanings, like a glossary. <dt> is the term and <dd> is the description. The lists of tags on this site are built this way.

<dl>
  <dt>HTML</dt>
  <dd>The structure of a web page.</dd>
  <dt>CSS</dt>
  <dd>The style of a web page.</dd>
</dl>

Result

HTML
The structure of a web page.
CSS
The style of a web page.

Good to know

Only <li> inside <ul> and <ol>
Do not put paragraphs or other tags directly inside the list tags. Put them inside an <li>.
Menus are lists
The navigation menu at the top of this site is a group of links. Many sites build menus as a <ul> inside <nav> and use CSS to remove the bullets.
Do not fake a list
Typing a dash or a number at the start of a line is not a list. Use the list tags so screen readers can say "list of 3 items".

Practice

  1. Make an ordered list of the steps to open your project in VS Code.
  2. Make an unordered list of your three favorite websites, each item a link.
  3. Write a description list with three HTML tags and what they do.
