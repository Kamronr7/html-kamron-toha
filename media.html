HTML Multimedia

HTML multimedia elements are used to display images, audio and video on a web page.

<img> Tag

Definition

The <img> tag is used to display an image on a web page.

Attributes

Attribute Role
src Specifies the path to the image.
alt Provides alternative text for the image.
width Specifies the width of the image.
height Specifies the height of the image.

Example Code

<img src="images/example.jpg" alt="Example image" width="300">

Result

<audio> Tag

Definition

The <audio> tag is used to play audio files on a web page.

Attributes

Attribute Role
controls Displays audio controls such as play and volume.
autoplay Starts playing the audio automatically.
loop Repeats the audio when it finishes.

Example Code

<audio controls>
    <source src="audio/example.mp3" type="audio/mpeg">
</audio>

Result

<video> Tag

Definition

The <video> tag is used to display and play video files on a web page.

Attributes

Attribute Role
controls Displays video controls.
width Specifies the width of the video.
height Specifies the height of the video.
autoplay Starts the video automatically.
loop Repeats the video when it finishes.

Example Code

<video width="400" controls>
    <source src="video/example.mp4" type="video/mp4">
</video>

Result

<source> Tag

Definition

The <source> tag is used to specify media files for audio and video elements.

Attributes

Attribute Role
src Specifies the location of the media file.
type Specifies the type of the media file.

Example Code

<video controls>
    <source src="video/movie.mp4" type="video/mp4">
</video>

Result

<figure> and <figcaption> Tags

Definition

The <figure> tag groups media content such as an image. The <figcaption> tag provides a caption for it.

Attributes

Attribute Role
class Assigns a CSS class to the element.
id Gives the element a unique identifier.

Example Code

<figure>
    <img src="images/example.jpg" alt="Example" width="300">
    <figcaption>Example image</figcaption>
</figure>

Result
