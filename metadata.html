Page 9: Metadata

Metadata is information about your page, not part of the page itself. Visitors never see it, but browsers, search engines and chat apps read it.

See the essential tags

Where metadata lives

All metadata goes inside the <head> element, before <body>. Only the <title> shows up for visitors, in the browser tab.

The essential tags

Put these in the head of every page you build.

<head>
  <meta charset="UTF-8">
  <meta name="viewport"
        content="width=device-width,
                 initial-scale=1.0">
  <title>Metadata – Learn HTML</title>
  <meta name="description"
        content="What metadata is and
                 how to write it.">
  <meta name="author" content="Your name">
  <link rel="stylesheet"
        href="css/style.css">
</head>
charset
The text encoding. UTF-8 lets the page show any language and symbol correctly.
viewport
Makes the page fit phone screens instead of shrinking a desktop layout.
title
The name in the browser tab, bookmarks and search results. Make it different on every page.
description
A one or two sentence summary that search engines often show under the title.
author
Who made the page.
link
Connects the page to another file, such as a stylesheet or an icon.

Try it: write a search result

Edit the title and description to see how they could look in a search engine. Titles around 60 characters and descriptions around 160 characters fit best.

Share previews: Open Graph tags

When someone pastes your link into a chat or social app, it reads Open Graph tags to build the preview card.

<meta property="og:title" content="Learn HTML">
<meta property="og:description" content="Nine short pages for beginners.">
<meta property="og:image" content="images/preview.png">
<meta property="og:type" content="website">

Other useful tags:

<meta name="robots" content="noindex">
Asks search engines not to list this page.
<meta name="theme-color" content="#2547d0">
Colors the browser bar on many phones.
<link rel="icon" href="images/favicon.png">
The small icon in the browser tab.

The keywords meta tag is a common old habit. Search engines now ignore it, so you can skip it.

Look at any page's metadata

  1. Open any website.
  2. Press Ctrl+U (Cmd+Option+U on Mac) to view the source.
  3. Look at the top of the file, between <head> and </head>.

Practice

Open your index.html and add a description and an author meta tag to its head. Then change the <title> so it describes only that page.
