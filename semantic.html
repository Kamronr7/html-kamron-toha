Semantic HTML

Semantic HTML uses tags that describe the meaning and structure of the content on a web page.

<header> Tag

Definition

The <header> tag represents introductory content at the top of a page or section.

Attributes

Attribute Role
class Assigns a CSS class to the header.
id Gives the header a unique identifier.

Example Code

<header>
    <h1>My Website</h1>
</header>

Result

My Website

<nav> Tag

Definition

The <nav> tag is used for navigation links.

Attributes

Attribute Role
class Assigns a CSS class to the navigation.
id Gives the navigation a unique identifier.

Example Code

<nav>
    <a href="index.html">Home</a>
    <a href="forms.html">Forms</a>
</nav>

Result

Home Forms

<main> Tag

Definition

The <main> tag contains the main content of a web page.

Attributes

Attribute Role
class Assigns a CSS class to the main content.
id Gives the main content a unique identifier.

Example Code

<main>
    <p>This is the main content.</p>
</main>

Result

This is the main content.

<section> Tag

Definition

The <section> tag groups related content together in a page.

Attributes

Attribute Role
class Assigns a CSS class to the section.
id Gives the section a unique identifier.

Example Code

<section>
    <h2>About Us</h2>
    <p>Information about the website.</p>
</section>

Result

About Us

Information about the website.

<article> Tag

Definition

The <article> tag represents independent content such as a news article, blog post or forum post.

Attributes

Attribute Role
class Assigns a CSS class to the article.
id Gives the article a unique identifier.

Example Code

<article>
    <h2>HTML Basics</h2>
    <p>HTML is used to create web pages.</p>
</article>

Result

HTML Basics

HTML is used to create web pages.

<aside> Tag

Definition

The <aside> tag contains additional content related to the main content.

Attributes

Attribute Role
class Assigns a CSS class to the aside element.
id Gives the aside element a unique identifier.

Example Code

<aside>
    <p>Related information</p>
</aside>

Result

Related information

<footer> Tag

Definition

The <footer> tag represents the bottom section of a page or section.

Attributes

Attribute Role
class Assigns a CSS class to the footer.
id Gives the footer a unique identifier.

Example Code

<footer>
    <p>Copyright 2026</p>
</footer>

Result

Copyright 2026
