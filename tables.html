Page 5: Tables

Tables show data in rows and columns, like a timetable or a price list. Use them for data, not to arrange the layout of a page.

On this page: Basic table, Table parts, Merging cells

A basic table

Build a table row by row. <table> wraps everything, <tr> is a row, <th> is a heading cell and <td> is a data cell.

<table>
  <tr>
    <th>Tag</th>
    <th>Purpose</th>
  </tr>
  <tr>
    <td>&lt;p&gt;</td>
    <td>Paragraph</td>
  </tr>
  <tr>
    <td>&lt;a&gt;</td>
    <td>Link</td>
  </tr>
</table>

Result

TagPurpose
<p>Paragraph
<a>Link

To show a tag name as text, write &lt; for < and &gt; for >. Otherwise the browser reads it as a real tag.

Table parts

Larger tables use extra tags that give each part a meaning.

<table>
  <caption>Weekly study plan</caption>
  <thead>
    <tr>
      <th scope="col">Day</th>
      <th scope="col">Topic</th>
      <th scope="col">Hours</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <th scope="row">Monday</th>
      <td>Text tags</td>
      <td>2</td>
    </tr>
    <tr>
      <th scope="row">Tuesday</th>
      <td>Lists</td>
      <td>1</td>
    </tr>
  </tbody>
  <tfoot>
    <tr>
      <th scope="row" colspan="2">Total</th>
      <td>3</td>
    </tr>
  </tfoot>
</table>

Result

Weekly study plan
DayTopicHours
MondayText tags2
TuesdayLists1
Total3
<caption>
The title of the table. It must be the first thing inside <table>.
<thead>, <tbody>, <tfoot>
Group the heading rows, the main rows and the summary rows.
scope
Says whether a heading belongs to a column (col) or a row (row). Screen readers use it to read cells in context.

Merging cells

colspan makes a cell stretch across columns. rowspan makes it stretch down rows.

<table>
  <tr>
    <th colspan="2">Class schedule</th>
  </tr>
  <tr>
    <td rowspan="2">Morning</td>
    <td>HTML</td>
  </tr>
  <tr>
    <td>CSS</td>
  </tr>
</table>

Result

Class schedule
MorningHTML
CSS

When a cell spans two columns, leave out one <td> in that row. Each row must still add up to the same number of columns.

Good to know

Data only
Use tables for information that really has rows and columns. Page layout is done with CSS and the tags on Page 8.
Borders and spacing
HTML gives tables no borders by default. The look comes from CSS, which is why the tables on this site have borders in style.css.
Wide tables on phones
Wrap a wide table in a <div> that CSS lets scroll sideways.

Practice

  1. Build a table of your weekly schedule with a caption and heading row.
  2. Add a total row at the bottom using <tfoot> and colspan.
  3. Add scope to every heading cell.
