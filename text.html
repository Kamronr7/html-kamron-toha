HTML Text Formatting

HTML has different tags for creating headings, paragraphs and formatting text.

<p> Tag

Definition

The <p> tag is used to create a paragraph.

Attributes

Attribute Role
class Assigns a CSS class to the paragraph.
id Gives the paragraph a unique identifier.

Example Code

<p>This is a paragraph.</p>

Result

This is a paragraph.

<h1> Tag

Definition

The <h1> tag is used for the most important heading on a page.

Attributes

Attribute Role
class Assigns a CSS class to the heading.
id Gives the heading a unique identifier.

Example Code

<h1>My Website</h1>

Result

My Website

<strong> Tag

Definition

The <strong> tag marks text as important. Browsers usually display it in bold.

Attributes

Attribute Role
class Assigns a CSS class to the element.
id Gives the element a unique identifier.

Example Code

<p>This is <strong>important</strong> text.</p>

Result

This is important text.

<em> Tag

Definition

The <em> tag is used to emphasize text. Browsers usually display it in italic.

Attributes

Attribute Role
class Assigns a CSS class to the element.
id Gives the element a unique identifier.

Example Code

<p>This is <em>important</em> information.</p>

Result

This is important information.

<br> Tag

Definition

The <br> tag creates a line break.

Attributes

Attribute Role
class Assigns a CSS class.

Example Code

Hello<br>World

Result

Hello
World

<hr> Tag

Definition

The <hr> tag creates a horizontal line between sections of content.

Attributes

Attribute Role
class Assigns a CSS class.

Example Code

<p>First section</p>
<hr>
<p>Second section</p>

Result

First section

Second section
